# 3D-Tic-Tac-Toe 🧩

A 3D-style Tic-Tac-Toe clone built with LÖVE 2D — my first game project.  
You can play a simple 3-in-a-row game, with interactive 3D-like view.

## 🌟 Features  
- 3D-style board representation (using 2D rendering tricks in LÖVE 2D)  
- Simple and intuitive two-player gameplay  
- Cross-platform (runs wherever LÖVE supports)  

## 🎮 Play / How to Run  
1. Make sure you have [LÖVE 2D](https://love2d.org) installed.  
2. Clone the repo:  
   ```bash
   git clone https://github.com/SpaceSHEEEEP/3D-tic-tac-toe.git
   ```
3. Run with LÖVE:
  ```bash
      love 3D-tic-tac-toe
  ```
4. Optionally — or download the provided release for Windows (see Releases tab) - or download it from itch.io https://space-sheeeeeeep.itch.io/3d-tic-tac-toe
